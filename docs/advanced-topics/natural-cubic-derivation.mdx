# Natural Cubic Splines — The Derivation

<Difficulty level="Hard" />

<Abstract>
The [Splines lesson](../path-following/quintic-splines.mdx) introduces the natural cubic spline as the
cheapest C² curve through a set of points and shows it in action. This page is the full derivation: turn the
continuity conditions into a single <strong>tridiagonal</strong> system in the second derivatives
("moments"), solve it in $O(n)$ with the <strong>Thomas algorithm</strong>, and read off each cubic piece —
plus why a robot path actually needs two of these splines.
</Abstract>

<Admonition type="note" title="Readiness and stopping point">

This page extends [**Splines**](../path-following/quintic-splines.mdx). It assumes you know that a natural
cubic spline lays one cubic per interval, is C² across every interior knot, and uses the *natural* boundary
$S''(x_0) = S''(x_n) = 0$. You should also be comfortable with derivatives and Gaussian elimination. If
your path library already builds natural or quintic splines, you may stop at the core lesson; this page is
for readers implementing or auditing the solver.

</Admonition>

## Conditions to a tridiagonal system

Lay a cubic $S_i(x)$ on each interval $[x_i, x_{i+1}]$ and impose:

- **C⁰**: each piece hits its endpoints, $S_i(x_i) = y_i$ and $S_i(x_{i+1}) = y_{i+1}$;
- **C¹ and C²**: neighbouring pieces share first *and* second derivative at every interior knot.

That is two conditions short of a unique solution. The **natural** boundary closes the gap by setting
the scalar/component second derivative to zero at the two ends, $S''(x_0) = S''(x_n) = 0$ — the spline leaves the path straight, like a
drafting spline released at its tips.

Writing the unknowns as the second derivatives ("moments") $M_i = S''(x_i)$ collapses all of that into a
single **tridiagonal** system. With knot spacing $h_i = x_{i+1} - x_i$:

$$
\begin{gathered}
h_{i-1} M_{i-1} + 2(h_{i-1} + h_i)\,M_i + h_i M_{i+1} \\[2pt]
= 6\!\left(\frac{y_{i+1} - y_i}{h_i} - \frac{y_i - y_{i-1}}{h_{i-1}}\right),
\\[4pt]
M_0 = M_n = 0
\end{gathered}
$$

Each row touches only three unknowns. With the moments in hand, the piece on $[x_i, x_{i+1}]$ is

$$
\begin{aligned}
S_i(x) ={}& \frac{M_i (x_{i+1}-x)^3 + M_{i+1}(x - x_i)^3}{6 h_i} \\[3pt]
&+ \left(\frac{y_i}{h_i} - \frac{M_i h_i}{6}\right)(x_{i+1}-x)
 + \left(\frac{y_{i+1}}{h_i} - \frac{M_{i+1} h_i}{6}\right)(x - x_i)
\end{aligned}
$$

Drag the waypoints below: the spline always threads through every point. Its component first and second
derivatives match at every knot; wherever the 2-D tangent is nonzero, that C² regularity makes the
curvature comb continuous. The natural boundary $M_0=M_n=0$ flattens the component second derivatives at
the ends.

## Solving it in O(n): the Thomas algorithm

Because each row touches only three unknowns, you never form or invert a general matrix. The **Thomas
algorithm**: Gaussian elimination specialised to a tridiagonal system — does a forward sweep that
eliminates the sub-diagonal, then a back substitution, both linear in the number of points:

<Pseudocode label="Natural cubic spline: solve the tridiagonal moment system">{`NATURAL CUBIC SPLINE MOMENTS
  Finds M[i], the second derivative at each knot, for a spline through
  the points (x[i], y[i]).

  require x and y are the same length, at least 2, all finite
  require x is STRICTLY increasing         # h[i] must be positive

  h[i] <- x[i+1] - x[i]      for each interval

  # ---- build the tridiagonal system ----
  #   sub[i]*M[i-1]  +  diag[i]*M[i]  +  sup[i]*M[i+1]  =  rhs[i]

  diag[first] <- 1,   diag[last] <- 1,   rhs at both ends <- 0
  # ^ the NATURAL boundary condition: M = 0 at both ends, meaning the
  #   spline straightens out at the extremes. Work out what that looks
  #   like physically, and what a robot path does at its endpoints.

  for each interior knot i:
      sub[i]  <- h[i-1]
      diag[i] <- 2 * (h[i-1] + h[i])
      sup[i]  <- h[i]
      rhs[i]  <- 6 * ( (y[i+1]-y[i])/h[i]  -  (y[i]-y[i-1])/h[i-1] )

  # Derive that row. Continuity of the FIRST derivative at knot i, with a
  # cubic on each side written in terms of M[i-1], M[i], M[i+1], gives
  # exactly this equation. Work through one interior knot with equal
  # spacing (all h the same) - the row collapses to 1, 4, 1 and the right
  # side becomes a second difference. Look up: "natural cubic spline
  # derivation", "moment equations".

  # ---- solve it with the Thomas algorithm: O(n), not O(n^3) ----
  forward sweep, for each i from the second row down:
      m       <- sub[i] / diag[i-1]
      diag[i] <- diag[i] - m * sup[i-1]
      rhs[i]  <- rhs[i]  - m * rhs[i-1]

  back substitution:
      M[last] <- rhs[last] / diag[last]
      for each i from last-1 back to the first:
          M[i] <- (rhs[i] - sup[i] * M[i+1]) / diag[i]

  return M

# The Thomas algorithm is just Gaussian elimination that skips every entry
# it already knows is zero. Work out the cost of general elimination on an
# n by n matrix versus this, and why that matters for a path resampled to
# hundreds of points on a Control Hub.
# Look up: "Thomas algorithm", "tridiagonal matrix algorithm".
#
# Feed the resulting M[i] and M[i+1] into the segment formula above to
# evaluate the spline anywhere inside interval i.
`}</Pseudocode>

## A path is not a function

<Callout type="warning" title="Fit x(t) and y(t), not y(x)">
$S(x)$ needs $x$ to increase monotonically — a robot path that doubles back has two $y$'s for one $x$.
Fit <strong>two</strong> natural cubic splines instead, $x(t)$ and $y(t)$ against the point index (or arc
length) $t$, and evaluate them together. The same fix applies to any interpolating spline used as a 2-D
trajectory. So for a 2-D path, run <code>naturalCubicMoments</code> twice — once for $x(t)$ and once for
$y(t)$ against the index $t$.
</Callout>

The trade against quintic Hermite is the one from the core lesson: a natural cubic is already C² with the
fewest degrees of freedom and no slope input, but the natural boundary pins the component second
derivatives to zero — you don't get to choose them. For a 2-D path this implies zero endpoint curvature
only where the tangent $(x'(t),y'(t))$ is nonzero; a zero tangent makes curvature undefined. A quintic's
extra coefficients per segment buy that boundary control.
