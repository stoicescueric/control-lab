# Module 4 · Signal Processing

Every sensor lies a little. A distance sensor spikes, a vision pose jitters from frame to frame, an
IMU heading drifts. A controller fed raw, noisy measurements amplifies that noise straight into your
motors — the derivative term is especially merciless. This module is about *cleaning the signal
before you control it*, and it comes in two distinct halves.

## Part 1 — Filtering: one sensor, less noise

A filter takes a single noisy stream and smooths it, trading a little lag for a lot of calm:

- **[Signals & Noise](./signals.mdx)** — what sensor noise actually looks like, which sensors carry
  it (and which, like encoders, don't), and how to measure it before filtering anything.
- **[Low-pass filtering](./low-pass.mdx)** — the exponential moving average, the one-line filter you
  will reach for most.
- **[Moving average](./moving-average.mdx)** — the windowed alternative, and when its latency is
  worth its smoothness.

Filtering has a hard limit: it fights *jitter*, not *drift*. If a sensor's center is walking away
from the truth, no amount of smoothing brings it back — you need a second opinion.

## Part 2 — Fusion: two sensors, one estimate

Fusion combines two imperfect sensors whose failures point in opposite directions:

- **[Complementary filter](./complementary.mdx)** — the simplest fusion: a fast-but-drifting motor
  encoder anchored by a slow-but-honest absolute encoder, blended with one constant.
- **[1-D Kalman filter](./kalman.mdx)** — the same blend, except the weight is computed optimally
  every step from how uncertain each source actually is.
- **[Extended Kalman Filter (EKF)](./ekf.mdx)** — the same machinery on the nonlinear measurements
  real localisation is made of, like AprilTag vision.

<Admonition type="tip" title="Filters and controllers are a team">

A controller is only as good as the signal it sees. The cleanest controller code in the world will
still oscillate on a noisy distance sensor. Master this module before you trust the controllers in
[Module 2](../control-theory/index.mdx).

</Admonition>

Start with [Signals & Noise](./signals.mdx), work through the two filters, then cross into fusion
with the complementary filter and the Kalman family.
